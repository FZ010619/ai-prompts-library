# AI Prompts Library

一个公开、持续维护的中文 AI 提示词仓库。这里收录可复用的提示词，并在本 README 中说明每份提示词的基本用途。

## 提示词目录

| 提示词 | 基本用途 | 适用场景 |
| --- | --- | --- |
| [沉陷论文精简总结提示词](prompts/academic-paper-summary.md) | 将采矿沉陷及相关论文整理为结构紧凑的 Markdown 总结，集中呈现参数、过程与结果，并区分不同数据来源。 | 论文精读、文献数据库整理、研究资料归档 |
| [综合大卡 APKG 持续学习提示词](prompts/anki-apkg-continuous-learning.md) | 将持续学习内容整理或更新为少量综合型 Anki 卡片，并约束牌组稳定标识、内容密度、隐私处理与交付校验。 | Anki 制卡、长期牌组维护、阶段性复习 |

## 使用方法

1. 打开上表中的提示词文件。
2. 复制适合当前任务的提示词或指令段落。
3. 按提示词中的占位说明补充主题、材料或牌组名称。
4. 将完整内容发送给支持相应任务的 AI 工具。

## 添加新提示词

1. 在 `prompts/` 中新增一个 Markdown 文件。
2. 在“提示词目录”表格中添加文件链接、基本用途和适用场景。
3. 在提交前运行：

   ```bash
   python scripts/check_readme_index.py
   ```

GitHub Actions 会在推送和拉取请求中执行同样的检查。如果新增提示词却没有同步更新 README，检查将失败。

## 维护原则

- 一份文件只解决一类清晰任务。
- 尽量保留提示词的原始完整内容。
- 新增提示词时必须同步更新 README 的用途说明。
- 修改提示词后，如用途或适用场景发生变化，也必须同步修改 README。
- 不提交账号令牌、密码、真实坐标等敏感信息。

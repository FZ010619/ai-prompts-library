## 使用方法

1. 打开上表中的提示词文件。
2. 复制适合当前任务的提示词或指令段落。
3. 按提示词中的占位说明补充主题、材料或牌组名称。
4. 将完整内容发送给支持相应任务的 AI 工具。

## 记忆卡输出格式

本仓库的[综合大卡持续学习提示词](prompts/anki-apkg-continuous-learning.md)同时支持两条并行工作流：

| 目标软件 | 输出格式 | 主要用途 |
| --- | --- | --- |
| Anki | `.apkg` | 生成或持续更新牌组，保持牌组、模型、笔记 GUID 和卡片结构稳定 |
| 墨墨记忆卡 | `.xlsx` | 通过 Excel 导入问答题、概念题或选择题 |

墨墨记忆卡支持的三种表头为：

- 问答题：`问题｜答案`；
- 概念题：`概念｜定义`；
- 选择题：`问题描述｜答案｜A 选项｜B 选项｜C 选项｜D 选项｜解析`。

> 墨墨记忆卡通过 Excel 识别卡片类型时，第一行必须保留对应格式的字段表头。没有表头可能无法识别或无法正常导入。

从第二行开始，每一行对应一张卡片。同一卡片的多项内容应放在同一个单元格内，并使用 Excel 单元格内部的真实换行，不要用字面字符串 `\n`，也不要把一张综合卡拆成多行。导入预览可能把表头显示为额外卡片；遇到这种情况应在导入后手动删除该卡，不能删除源文件表头。

每张卡必须控制在 2000 字以内，通常建议不超过约 1800 字；若软件分别计算正面、背面或整张卡片，以实际导入预览为准。选择题已实测至少支持 A—E 选项：确有需要时可在`D 选项`后、`解析`前增加`E 选项`，但不要为凑数强加 E；更多选项仍需根据目标软件实际导入结果验证。

推荐先完成一个相对完整的学习阶段，再选择目标软件与题型，按主题去重和组织综合卡，生成文件后检查表头、列序、真实换行、数量、字数、空白、重复、答案一致性、隐私和文件可打开性。默认一个 `.xlsx` 文件只使用一种表头；如果软件只能识别第一个工作表，不同题型应分别导出文件。

Excel 参考模板保存在 [`templates/flashcards/momo-flashcards-import-template.xlsx`](templates/flashcards/momo-flashcards-import-template.xlsx)。模板原表在一个工作表中依次展示三种表头；实际导入文件只应把本次所选题型的准确表头放在第一行。

简短示例：学习完一阶段 CAD 命令后，可以要求 AI“使用[综合大卡持续学习提示词](prompts/anki-apkg-continuous-learning.md)，按问答题格式生成墨墨记忆卡 `.xlsx`；第一行保留`问题｜答案`，从第二行起每行一张卡，答案单元格内用真实换行列出命令全称、用途、步骤、结果、错误与工程应用，每卡控制在约 1800 字以内”。

## 添加新提示词

1. 在 `prompts/` 中新增一个 Markdown 文件。
2. 在“提示词目录”表格中添加文件链接、基本用途和适用场景。
3. 在提交前运行：

   ```bash
   python scripts/check_readme_index.py
   ```

GitHub Actions 会在推送和拉取请求中执行同样的检查。如果新增提示词却没有同步更新 README，检查将失败。

## 维护原则

- 一份文件只解决一类清晰任务。
- 尽量保留提示词的原始完整内容。
- 新增提示词时必须同步更新 README 的用途说明。
- 修改提示词后，如用途或适用场景发生变化，也必须同步修改 README。
- 不提交账号令牌、密码、真实坐标等敏感信息。

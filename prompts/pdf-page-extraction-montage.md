# 批量 PDF 指定页提取与总览拼接开发提示词

## 用途

让编码 AI 检查 Python 环境并实现一个稳健工具：批量读取 PDF、提取指定页、可选裁剪、添加标题并拼接为总览图片。

## 可复制提示词

```text
角色：你是一名熟悉 Python、PyMuPDF 和 Pillow 的桌面数据处理工程师。

目标：在我当前项目中检查并修复/实现“批量 PDF → 指定页图片 → 排序 → 标题 → 拼接总览图”工具。请直接检查项目并完成代码和验证，不要只给理论说明。

环境与输入：
- 项目目录：【填写】
- PDF目录：【填写】
- 输出目录：【填写】
- 页码：【填写；明确按人类从1开始还是代码从0开始】
- 排序规则：【文件名日期/文件名自然排序】
- 列数：【填写】
- DPI：【填写】
- 裁剪区域或比例：【无则填None】
- 输出格式：【PNG/JPG】

依赖要求：
- 优先使用 `PyMuPDF`（导入名为 `fitz`）和 `Pillow`。
- 不要误装名为 `fitz` 的其他包。
- 先确认实际运行的 Python 解释器和虚拟环境，再判断依赖是否安装。
- 如果缺失，给出针对当前解释器的明确安装命令：`python -m pip install pymupdf pillow`。

功能成功标准：
1. 扫描目录中的所有 `.pdf`，扩展名大小写均可识别。
2. 优先解析文件名中的日期排序；无法解析日期时采用稳定的自然文件名排序。
3. 提取指定页并按 DPI 渲染；页码语义在界面和代码中一致。
4. 支持关闭裁剪或按明确坐标/比例裁剪，并验证裁剪范围有效。
5. 每张小图上方添加可读的 PDF 文件名，中文字体缺失时有安全回退。
6. 统一单元格尺寸，在保持纵横比的前提下缩放和留白，不拉伸图像。
7. 按指定列数拼接，并保存为 PNG 或高质量 JPG。
8. 单个 PDF 损坏、加密、页数不足或渲染失败时记录错误并继续，不中断整批。
9. 输出目录不存在时创建；没有 PDF 时给出清晰提示且不生成空白图。
10. 大批量处理时逐个关闭文档和中间图像，避免无界内存占用。

代码设计：
- 使用 `pathlib.Path`，路径不硬编码到业务函数。
- 将配置集中在命令行参数或清晰的配置区。
- 将扫描排序、日期解析、页面渲染、裁剪、标题绘制、拼接和保存拆成职责清楚的函数。
- 返回处理成功数、失败数、输出路径和失败详情。
- 不覆盖已有输出，除非我明确允许；可使用时间戳或递增后缀。

验证：
- 先运行最小导入测试：`import fitz` 与 `from PIL import Image`。
- 为日期解析、自然排序、页码越界和网格尺寸添加小型自动测试。
- 使用至少两个正常PDF和一个异常案例做冒烟测试；如果项目没有样本，生成最小临时测试文件或说明无法测试的原因。
- 打开或检查输出图的尺寸、文件数、标题、顺序和可读性。

输出：
1. 修改或创建的文件。
2. 修复的问题及根因。
3. 安装和运行命令示例。
4. 参数说明。
5. 测试命令与实际结果。
6. 失败文件日志位置。
7. 如仍有问题，我下一步应提供的完整错误信息。

权限边界：可以读取和修改当前项目、创建输出目录并运行非破坏性测试。安装依赖、覆盖输出、删除文件或修改项目外内容前先确认。

停止规则：核心流程通过测试并生成可检查的输出后停止；如果环境或样本阻塞验证，保留已完成代码并准确说明阻塞点。
```

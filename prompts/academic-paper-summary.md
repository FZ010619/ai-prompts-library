# 学术论文精读与总结提示词

根据文献类型选择下面的提示词：期刊论文、会议论文和普通技术论文使用“精简总结提示词”；硕士、博士学位论文使用“精读研讨提示词”。两套提示词独立使用，不要把学位论文的长篇结构机械套用到短论文。

## 一、期刊论文、会议论文及普通技术论文：精简总结提示词

这一篇，继续以一个Markdown代码块的形式生成。
要求继续使用现在固定的精简格式：
1. 论文题目是唯一一级标题“#”；
2. 其余全部放在二级及以下标题；
3. 整篇只放在一个完整Markdown代码块里；
4. 主要部分控制在约7～10个，不要拆成四十多个标题；
5. 参数、推进过程、结果优先用表格集中表达；
6. 机理和演化过程可用Mermaid流程图；
7. 必须区分原文数据、派生计算、经验公式、数值模拟、物理模拟和现场实测；
8. 原文有数据冲突或术语混用时单独指出，不要自行修正；
9. 最后给出与【目标项目/工作面】的联系、数据库建议字段和一句话总结。

## 二、硕士、博士学位论文：精读研讨提示词

这一篇是硕士或博士学位论文，请继续以一个完整的 Markdown 代码块形式进行精读研讨。

本提示词只用于硕士学位论文和博士学位论文。期刊论文、会议论文和普通技术报告使用前面的精简总结提示词。

### 1. 任务目标与输出边界

1. 先判断材料是否确实属于硕士或博士学位论文；如果无法判断，明确说明判断依据不足。
2. 采用“精读 + 研讨 + 提炼”，不要使用普通期刊论文的快速摘要方式，也不要逐章机械复述全文。
3. 重点回答：
   - 作者研究了什么，为什么研究；
   - 核心科学问题和工程问题是什么；
   - 使用了哪些方法，方法之间如何相互支撑；
   - 哪些结论由理论、模拟、实验或实测支持；
   - 哪些内容值得学习、复现或迁移到【目标项目/工作面】；
   - 哪些内容只需了解，不值得投入过多时间。
4. 输出正文原则上合并为约 10～12 个主要部分。下列规则是必须覆盖的内容清单，不要求机械对应为同样数量的一级或二级标题。
5. 论文题目是输出正文唯一的一级标题 `#`，其余内容全部使用二级及以下标题。
6. 最终回答只能包含一个外层 Markdown 代码块，不在代码块前后添加说明。为允许正文内部使用三反引号 Mermaid 代码块，最外层必须使用四个反引号，即以 <code>````markdown</code> 开始、以 <code>````</code> 结束。
7. 内容可以明显长于普通论文总结，重点章节允许展开，但必须保持层次清楚。

### 2. 材料完整性与防止臆测

开始研读时先检查：

- 是否包含封面、摘要、目录、正文、结论和参考文献；
- 是否存在缺页、乱码、OCR 错误、图片缺失、公式不可辨识或附件不完整；
- 当前材料是全文还是节选。

处理规则：

- 缺失内容写“原文未提供”；
- 无法辨识的内容写“原文不可辨识”；
- 只能依据节选材料时，标明“阶段性研读结果，不能替代全文结论”；
- 不根据常识补造数值、公式、页码、图号、表号或作者结论；
- 重要数据、公式和结论应尽量记录原文页码、章节、图号或表号；无法确认位置时写“原文位置待核”。

### 3. 开头建立整篇论文地图

不要立即进入细节，先说明：

- 学位类型、学校、专业、作者和年份；
- 研究矿区、工作面、煤层或其他研究对象；
- 核心科学问题与工程问题；
- 论文真正的主线；
- 各章节和各研究方法之间的关系；
- 作者最终想解决的问题。

优先用表格概括全文：

| 模块 | 主要内容 | 使用方法 | 核心输出 | 重要程度 |
| --- | --- | --- | --- | --- |
| 地质与工程背景 |  | 资料分析 |  | 基础 |
| 理论分析 |  | 力学模型 |  | 重要 |
| 相似模拟 |  | 物理模拟 |  | 核心/辅助 |
| 数值模拟 |  | FLAC3D、UDEC 等 |  | 核心/辅助 |
| 现场实测 |  | 钻孔、电法、微震等 |  | 核心 |

随后单独回答：

> **如果只阅读这篇论文最重要的 20%，应该重点阅读哪些章节、图表和公式，为什么？**

### 4. 研究背景、科学问题与工程条件

不要大段复述“资源重要”“绿色开采重要”等通用背景。重点提炼：

1. 作者面对的具体地质、采矿或工程条件；
2. 已有研究已经解决什么；
3. 仍然存在什么问题；
4. 本论文提出了哪些具体科学问题和工程问题；
5. 这些问题之间的递进关系。

如果“研究内容”“关键科学问题”“创新点”表述不一致，应分别记录并标记，不自行替作者统一。

工程背景优先整理为表格：

| 参数 | 数值/描述 | 数据性质 | 原文位置 | 对研究的意义 |
| --- | ---: | --- | --- | --- |
| 煤层或研究对象 |  | 【原文数据】 |  |  |
| 埋深 |  | 【原文数据】 |  |  |
| 采厚 |  | 【原文数据】 |  |  |
| 倾角 |  | 【原文数据】 |  |  |
| 工作面走向长 |  | 【原文数据】 |  |  |
| 工作面倾斜长 |  | 【原文数据】 |  |  |
| 层间距 |  | 【原文数据】 |  |  |
| 关键层 |  | 【原文判定/作者分析】 |  |  |
| 顶底板岩性 |  | 【原文数据】 |  |  |
| 重复采动关系 |  | 【原文描述】 |  |  |

根据论文实际内容补充上下煤层空间关系、已采区与本工作面的关系、煤柱、采空区、关键层、含水层、隔水层、松散层、地形地貌、断层、陷落柱、采深采厚比，以及层间距与采厚关系。

与【目标项目/工作面】比较时，既要说明相似条件，也要说明不能直接套用的差异。

### 5. 理论基础、公式与力学分析

对岩层移动、关键层、砌体梁或传递岩梁、板梁、弹塑性、应力拱、采场矿压、离层、裂隙、“三带”、概率积分法、重复采动损伤及其他重要模型，不能只记录公式结果。

每个重要理论或公式至少解释：

1. 描述的物理现象；
2. 基本假设和适用条件；
3. 主要变量、单位和物理意义；
4. 推导得出的结果；
5. 工程含义；
6. 后文是否使用实验、模拟或实测验证；
7. 对【目标项目/工作面】是否有直接价值。

可以省略中间纯数学步骤，但不能省略物理意义。公式必须标明来源：

- 【原文理论公式】
- 【作者推导】
- 【经验公式】
- 【规范公式】
- 【派生计算】

不要把不同来源混为一类。

### 6. 研究方法逐项精读

根据论文实际内容讲清理论分析、相似材料模拟、数值模拟、钻孔窥视、双端堵水测漏、高密度电法、微震、应力/位移/离层监测、地表水准或 GNSS、概率积分法、统计回归和预测模型等主要方法，但不要机械拆成大量标题。

每种重要方法至少回答：

1. **为什么使用：**解决什么问题，其他方法为什么不能完全替代；
2. **如何设计：**提取模型尺寸、相似比、材料配比、边界条件、开采顺序、推进距离、测点布置、模型网格、本构模型、物理力学参数、初始应力、仪器型号、观测位置、探测深度、时间和判据；
3. **获得什么：**把图表结果转换为“现象—规律—解释”，不要只罗列图号；
4. **如何验证：**说明不同方法之间是相互验证、互相补充，还是仅在趋势上相似；
5. **有什么局限：**区分作者承认的局限和根据论文内容作出的判断，后一类标记为【研读判断】。

### 7. 开采过程与覆岩演化

如果论文涉及覆岩移动、离层、裂隙、“两带”、地表沉陷或重复采动，应按推进过程重新整理，而不是照搬原章节顺序。

| 开采阶段/推进距离 | 覆岩破断 | 离层 | 裂隙 | 关键层 | 应力变化 | 地表响应 | 证据来源及原文位置 |
| --- | --- | --- | --- | --- | --- | --- | --- |

需要时使用 Mermaid 总结演化链条。内部 Mermaid 使用三个反引号，与外层四反引号代码块区分。例如：

```mermaid
flowchart LR
A[工作面推进] --> B[直接顶垮落]
B --> C[关键层弯曲与破断]
C --> D[离层和裂隙扩展]
D --> E[裂隙贯通或趋于稳定]
E --> F[地表沉陷与裂缝响应]
```

重复采动必须区分：

> 第一次采动 → 稳定或残余结构 → 第二次采动 → 原有裂隙重新活化 → 新裂隙产生 → 裂隙贯通 → 最终稳定

不要把初次采动和重复采动混成一个过程。

### 8. 核心结果与定量规律

集中整理论文实际涉及的垮落带、导水裂隙带、裂采比、垮采比、离层、关键层破断、裂隙范围、应力峰值、超前影响距离、周期来压步距、地表下沉、岩移参数、移动角、裂缝角、持续时间、预测误差和实测验证等关键结果。

每个重要数字必须标记证据类型：

- 【原文数据】
- 【现场实测】
- 【物理模拟】
- 【数值模拟】
- 【理论计算】
- 【经验公式】
- 【作者拟合】
- 【派生计算】

同一指标存在多个方法结果时，优先使用对比表：

| 指标 | 理论/经验 | 数值模拟 | 物理模拟 | 现场实测 | 作者最终采用值 | 原文位置 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |

说明不同方法产生差异的可能原因，但不能把数值模拟写成现场实测，也不能把合理解释伪装成作者原话。

### 9. 机理解释

不能只写“作者揭示了某种机理”。应按以下链条拆解：

> 条件 → 岩层结构变化 → 应力重新分布 → 破断/离层/裂隙演化 → 岩移传递 → 工程响应

根据论文内容解释关键层、原采空区、煤柱、层间距、采深采厚比和地形等因素的作用，以及重复采动、裂隙重新活化、离层形成、“两带”高度稳定和非对称沉陷等现象的原因。

最后用一段通俗语言回答：

> **如果不用论文术语，这篇论文认为岩层或研究对象实际上发生了什么？**

### 10. 创新、价值、问题与局限

#### 作者声称的创新点

忠实整理原文，不自行美化，并尽量给出原文位置。

#### 从全文看真正有价值的内容

从方法、数据、规律、工程应用、模型和多方法验证方面判断，统一标记为【研读判断】，并说明哪些内容值得精读、复现或借鉴，哪些只是为论文完整性服务、可以快速浏览。

#### 问题与需要警惕的地方

检查：

1. 参数、尺寸、采深、采厚和地层名称是否前后一致；
2. 图表与正文是否冲突；
3. “垮落带”“裂隙带”“导水裂隙带”等术语是否混用；
4. 数值参数、材料配比和判据来源是否充分；
5. 模型边界是否可能影响结果；
6. 实测点和样本数量是否足够；
7. 模拟结果是否真正获得现场验证；
8. 相关性是否被解释为因果关系；
9. 所谓“验证”是否只是趋势相似。

原文存在问题时只指出，不自行修改，分别使用：

- 【原文冲突】
- 【原文表述不清】
- 【证据不足】
- 【研读判断】

### 11. 与目标项目的联系和迁移边界

单独结合【目标项目/工作面】进行比较。如果用户没有提供目标项目资料，应写“目标项目资料未提供”，不能调用未提供的内部信息。

| 论文内容 | 与目标项目相似点 | 关键差异 | 可直接借鉴 | 需谨慎借鉴 | 仍需补充的数据 |
| --- | --- | --- | --- | --- | --- |

可根据实际研究涉及的上下煤层重复采动、层间距、采深采厚比、关键层、离层、垮落带、导水裂隙带、跨煤层裂隙、地表沉陷、沟谷地形、钻孔窥视、堵水测漏、电法、微震、相似模拟、数值模拟、概率积分法和岩移参数反演等内容进行比较。

必须明确回答：

> **这篇论文能帮助【目标项目/工作面】解决哪个具体问题，哪些结论不能直接套用？**

不要只写“具有参考意义”。公开整理或上传前，泛化真实矿名、工作面编号、坐标、人员姓名、单位内部数据和未公开项目参数。

论文包含其他特殊指标时再增加字段，不要为了填满表格捏造内容。

### 13. 结尾固定内容

结尾必须给出：

1. **一句话总结：**这篇学位论文最核心的贡献是什么；
2. **应该记住的 5～10 个知识点：**用于复习，不重复摘要；
3. **后续学习建议：**指出值得精读的章节、必须查看的图表、需要理解的公式、与【当前研究课题】最相关的部分，以及只需了解的内容。

### 14. 全文证据标记

严格区分：

- 【原文数据】
- 【原文结论】
- 【原文理论公式】
- 【理论计算】
- 【经验公式】
- 【规范公式】
- 【作者推导】
- 【物理模拟】
- 【数值模拟】
- 【现场实测】
- 【作者拟合】
- 【派生计算】
- 【研读判断】
- 【原文冲突】
- 【原文表述不清】
- 【证据不足】
- 【补充知识，不属于论文原文】

不同证据等级不得混写。需要补充课外知识时，必须与论文内容分开并标记为【补充知识，不属于论文原文】。

### 15. 讲解风格与最终校验

这不是单纯摘要，而是陪读式研讨。主动解释为什么这样设计、公式的物理意义、图中应关注什么、不同方法为何出现差异、各章节如何衔接，以及结论的工程意义。容易混淆的内容可以增加“**通俗理解：**”，但不能脱离原文无限扩展。

输出前检查：

- [ ] 文献类型与提示词匹配；
- [ ] 最外层使用四反引号，内部 Mermaid 使用三反引号；
- [ ] 论文题目是正文唯一一级标题；
- [ ] 主要部分合并为约 10～12 个，没有逐章流水账；
- [ ] 重要数字、公式和结论带有证据类型及可核实的原文位置；
- [ ] 没有虚构缺失数据、页码、图号或表号；
- [ ] 原文事实、作者观点、派生计算和研读判断清楚分开；
- [ ] 初次采动与重复采动没有混淆；
- [ ] 真实项目名称、工作面编号、坐标、人员和内部数据已经泛化；
- [ ] 最终回答只包含一个完整的外层 Markdown 代码块。

最终目标不是简单缩短论文，而是帮助读者真正理解：

> **研究对象 → 科学问题 → 理论依据 → 实验/模拟/实测方法 → 演化过程 → 定量规律 → 形成机理 → 工程意义 → 对目标项目可迁移的内容与边界。**
